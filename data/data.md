# Dataset Description

## Overview

This project uses a large-scale body measurement dataset originally hosted on **Amazon Web Services (AWS)**.

The dataset contains personal body information and silhouette images collected from real human subjects. It was used to develop and evaluate the body measurement estimation approach.

## Dataset Characteristics

- **Data Type:** Structured and Image Data
- **Data Source:** Amazon Web Services (AWS)
- **Number of Subjects:** 2,505
- **Total Silhouette Images:** 8,978
- **Image Format:** Black-and-white body silhouettes
- **Image Views:** Frontal and lateral (side) views

## Dataset Features

Each subject's data includes:

### Personal Attributes
- Height
- Weight
- Gender

### Body Images
Two black-and-white silhouette images showing the subject's full body:
- Frontal view.
- Side view.

### Target Measurements

The dataset provides 14 body measurements in centimeters (cm):

1. Ankle Girth
2. Arm Length
3. Bicep Girth
4. Calf Girth
5. Chest Girth
6. Forearm Girth
7. Height
8. Hip Girth
9. Leg Length
10. Shoulder Breadth
11. Shoulder-to-Crotch Length
12. Thigh Girth
13. Waist Girth
14. Wrist Girth

## Data Access & Availability

The original dataset was accessed through a private AWS-hosted resource. However, access is currently unavailable, and the original dataset files cannot be redistributed or included in this repository.

The original AWS resource reference is provided below for documentation purposes:

**[Access the Original Dataset on AWS](https://registry.opendata.aws/bodym/)**

## Privacy Notice

The dataset contains personal body attributes and images of real individuals. The original data is therefore not included in this repository.
